## 1. 范式 (用户口述, 监督式 = 结果倒推, 非信号正推)

**核心**: 先用裸 K 线**全市场逐股**定义"赢家"(真实赚钱事件)= 标签 y, 再在**入场点**反推哪些
**PIT 特征组合**最能预测/选出赢家, 写成公式, train/OOS 时间外推验证。这**不是未来函数公式** —
是"用历史已知答案找特征 → 同条件再现时买入", 和 MACD 金叉被发现的逻辑同源。

### 1.1 两条 ground truth (标签 y, 裸 K 线全市场逐股扫)
- **主升浪**: 每只股(剔黑名单)每次**底→顶涨幅 > 60%** 的波段 = 一次主升浪。底=局部最低, 顶=局部最高。
- **公式 episode** (以 MACD 为范本): 每次**金叉买点→死叉卖点**, 其中**盈利 > 30%** 的 = 赢家 episode。
- 标签用全程后验算 (合法, 它是 y 不是特征)。

### 1.2 入场点 PIT 特征逐层叠加 (一个一个加, 不一次全开)
在赢家的**入场那一刻 (底部 / 金叉日)** 量化当时可见特征, 一个一个叠, 看哪个组合最能把赢家从
非赢家里分出来 (判据 = 含成本前向收益, **不是"赢家里常见"** — 必须看假阳率/非赢家也带否):
量 → 换手率 → 筹码分布 → 个股资金流 → 板块资金 → 概念资金 → 北向 → 增减持 → 盈利预测 …
(主升浪先叠"量价齐升"; MACD 先叠"零轴上下", 再叠上述)。

### 1.3 写公式 → 评估 → 分层
每个胜出的特征组合写成公式, 评估: **胜率 / 收益率 / 最大回撤 / 持仓周期 / 能抓出多少**。
然后**分层** (不可能同时适用大/小市值): 每公式按市值等维度逐层细分, 找**每公式的最佳参数 + 因子组合**。

### 1.4 train/OOS 时间外推 (用户口述的防泄露法)
- **train ≤ 2025-06** 建公式 (用已知答案找特征)。
- **OOS 2025-06 → 2026-06** 当未知验证 (模拟"2025-06 做的公式, 对未知一年")。
- 验证结果反哺优化, 指导今天以后的买卖。

### 1.5 Modal 规模搜索 (用户坚持: 本地算不过来)
全市场 × N 公式 × 因子栈 × 分层 × 参数 = 组合爆炸 → Modal。**铁律**: 规模越大多重比较越严重,
DSR/PBO 必须**按整个搜索空间规模**校正, 否则纯运气刷出假赢家 (放大 Optuna 过拟合反例)。

## 2. 两条防泄露铁律 (违者作废)

1. **特征只用入场那刻及之前的值** — 绝不碰这波涨幅/episode 自己的未来 K 线; "它后来成了赢家"这个
   事实绝不当特征 (S3 zhushenglang AUC 0.779 REJECT 就栽在结局派生量 follow_net_return 当特征)。
2. **OOS 段 (2025-06 后) 构建公式时绝不碰** — 只在 train 上找特征/定参数, holdout 一次性验证不回看。

## 4. 验收 (含成本 R1 + KPI, 每公式/cell)

PIT 干净 (入场前特征 + buyable-only IC) → OOS 含成本前向收益 > 0 → DSR/PBO (按搜索规模) →
含成本 execution-aware 组合回测 KPI 四项真触发 → 子周期稳定 (含 2024 微盘崩盘 + OOS 段)。
**单 episode/per-trade 口径 ≠ 组合 NAV; KPI 只认含成本组合回测。** IC 仅 necessary 快筛。

## 2. 核心结论

### 2.1 LHB 龙虎榜是项目最强的**反向**信号

- 上榜后 20d 超额 -3.21%, 60d 超额 -5.80%, 超额胜率仅 30%
- 高换手 LHB 更惨: 60d 超额 **-9.89%**, 胜率 24%
- 机构净买席位 LHB 也是负的(-5.80% @60d)

**含义**: 龙虎榜 = **见光死**。上榜代表已经被市场充分注意到(涨幅偏离/高换手触发), 此时介入系统性跑输大盘 6-10%。

### 2.2 "得主力者得天下"在明面主力数据层面证伪

北大 PPT 核心 "得主力者得天下 / 寻找主力跟随主力" — 在 A 股**可获取的主力行为数据(LHB/资金流/机构持仓链)层面完全证伪**:
- 能看到的主力行为(上龙虎榜)= 已经见光 = 反向
- 机构持仓链跟随 = 随机(胜率 50%)
- 资金流"主力买"信号 = 反向

### 2.3 跟主升浪研究完全一致(交叉验证)

之前主升浪研究发现:
- 真主升浪起涨前**无 LHB 痕迹**(688257 起涨前 90 天 0 次 LHB)
- LHB 机构席位单因子 precision 6% < base rate 9.5%(lagging)

本次 event study 进一步量化: LHB **不只是 lagging, 是 leading 反向**(上榜后跑输)。两个独立研究互证。

## 3. 对市场感知优化方向的含义(再次修正)

| 数据维度 | 实证 forward alpha | 该不该做 |
|---|---|---|
| LHB 龙虎榜(跟随) | [高危] 强反向 -5~10% | [NG] 不做跟随; [OK] 可反向用(上榜规避/做空) |
| 资金流"主力买"(跟随) | [高危] 反向 | [NG] 不做跟随 |
| 机构持仓链跟随 | [中性] 随机 | [NG] 价值低 |
| 机构调研/大宗(跟随) | [中性] 中性, 样本少 | 警告: 待更长样本 |
| 板块轮动(L1/L2/申万) | [中性] 均值回归无 alpha | [NG] 不做(前文已证) |
| **regime/emotion 大盘择时** | [OK] V12 fold 诊断有价值 | [OK] 做 |
| **个股量价 ML(V12-V17)** | [OK] 70% 胜率 | [OK] 做 |
| 概念主题层 | [?] 缺历史数据无法验证 | [待] 先积累 |

### 关键洞察

**市场感知不该往"跟随明面主力"方向做 — 那是反向的。** 真正的 alpha 在:
1. **大盘 regime 择时**(emotion/regime, 已验证)
2. **个股量价 ML**(V12-V17 主升浪识别, 70% 胜率)
3. **"还没被市场发现的"**(主升浪起涨前安静吸筹, 不是已上榜的)

LHB 反向信号本身可以**反过来用**: 把"近期上龙虎榜"作为**规避/减分**因子, 而不是加分。

## 4. 对 P0/P1 数据落库优先级的影响

本发现**不否定** P0/P1 落库, 但调整价值排序:

| 落库项 | 维度 | 本发现影响 |
|---|---|---|
| attention 关注度(P0) | 关注度(非主力跟随) | 警告: 关注度高可能也是反向(类似 LHB 见光), 落库后需验证方向 |
| profit_forecast 景气度(P0) | 基本面景气度 | [OK] 不受影响, 景气度是独立维度 |
| 概念主题(P1) | 题材轮动 | [OK] 不受影响, 概念是独立维度 |
| 融资融券(P2) | 杠杆资金情绪 | 警告: 可能也是反向(拥挤度), 落库后验证 |
| LHB 历史(已有) | 主力跟随 | [高危] 本发现证明反向, **不值得加强** |

**修正**: 落库后**第一件事是验证信号方向**(正向 alpha / 反向规避 / 随机), 不要假设"主力数据=利好"。

## 5. 沉淀(防再走弯路)

> 写入项目教训: **A 股可获取的"主力行为"数据(LHB/资金流/机构持仓链)作为 forward 跟随信号是反向或随机的, 不要往"跟随明面主力"方向建市场感知。能看到的主力行为=见光死。真 alpha 在 regime 择时 + 个股量价 ML + 起涨前安静吸筹识别。LHB 应反向用(规避/做空)。**

## 6. 一句话总结

event study 实证: **项目现有所有"主力跟随"类市场感知信号(LHB 全部/机构净买/高换手/资金流/持仓链)forward 超额收益是反向(-3~-10%)或随机, LHB 龙虎榜是最强反向信号(上榜后 60d 跑输大盘 5.8%, 高换手 9.9%)**。这跟主升浪研究"真主升浪起涨前无 LHB 痕迹"完全互证, 也彻底证伪了"得主力者得天下"在明面主力数据层面的可行性。**市场感知的 alpha 不在跟随明面主力(反向), 在 regime 择时 + 个股量价 ML + 识别还没被发现的吸筹。LHB 反过来可作规避因子。**

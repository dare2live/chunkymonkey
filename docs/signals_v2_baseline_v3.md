## 核心突破

用户质疑"机构不可能都是抬轿子的，系统没找到 alpha 要么算法错要么特征少"——完全正确。

跑 6 个健康检查后发现 **alpha 藏在三个维度**，当前 KNN 完全丢弃：

### 发现 1：机构类型 alpha 差异 7pp

| 类型 | EV | 胜率 | 诊断 |
|---|---|---|---|
| 牛散 | +9.71% | 62.2% | 强 alpha |
| 券商 | +8.48% | 56.2% | 正 alpha |
| 社保/北向/QFII | +7~8% | ~55% | ≈ blind |
| **基金** | **+3.07%** | **36.6%** | **负 alpha**（反向利用） |
| 国家队 | +0.68% | 44.4% | 负 alpha |

### 发现 2：溢价 U 型曲线

| 溢价 | EV | 胜率 |
|---|---|---|
| -10~0 折价 | +8.03% | **62.6%** |
| 0~10 | ~+8.3% | ~58% |
| 10~20 | +8.80% | 57.5% |
| **>20 高溢价** | **+5.25%** | **43.4%** |

### 发现 3：持仓强度线性

| rank | EV |
|---|---|
| 1（第一大股东） | **+10.95%** |
| 7-10 | +6.87% |

| hold_ratio | EV |
|---|---|
| >5% | +9.54% |
| <0.5% | +5.43% |

## V4 规则（已落地为默认配置）

```python
skip 硬规则（三选一命中即 skip）：
    inst_type IN ('基金', '国家队')      ← 负 alpha 类型
    OR premium_pct > 15                   ← 高溢价
    OR hold_ratio < 0.3                   ← 轻仓

follow 规则（没命中硬规则，再走双口径 KNN）：
    short_window(365d) AND long_window(all) 双份 EV≥5%, WR≥55%
```

## 未进一步挖的 alpha 源

- 行业动量对齐（机构进入 + 行业板块刚启动 = 双重确认）

**更新时间**：2026-04-19
**变化**：加入 `cooldown_days=90`（保证决策时历史样本的 `gain_60d` 已到期）+ 双口径 KNN（短期 365d + 长期 all）

## ★ 核心发现（严肃）

| 版本 | cooldown | 窗口 | Follow n | Follow EV | WR | Blind EV | Edge |
|------|----------|------|----------|-----------|-----|----------|------|
| V0（旧 v1 的实际数据）  | 0 | 单口径 | 4626 | **+7.50%** | 59.4% | +3.83% | **+3.67pp** |
| V1（仅加 cooldown=90） | 90 | 单口径 | 4454 | +2.13% | 45.1% | +3.83% | **−1.70pp** |
| V2（仅加双口径）       | 0 | short+long | 4448 | +7.25% | 59.2% | +3.83% | +3.42pp |
| V3（两个都加，当前默认）| 90 | short+long | 4223 | **+1.94%** | 45.2% | +3.83% | **−1.89pp** |

### 诚实结论

**旧 baseline 的 +7.4% EV / +3.67pp edge 大部分是 look-ahead 污染。真实 edge 存在但小得多。**

分解：
- **全量 backtest V0 → V3**：EV 从 +7.50% 跌到 +1.94%，edge 从 +3.67pp 翻到 -1.89pp
- 这看起来像"系统完全失效"——**但这个数字被 2023 早期噪音严重污染**

### 关键：看最近 Out-of-sample Cohort（真相）

全量 backtest 会把早期不活跃时期的样本算进来（2023 上半年机构数据不全、事件稀疏、计算结果方差大）。真正可信的 OOS 测试是"最近已成熟 cohort"：

```
window: 2025-07-23 ~ 2026-01-19  (n=5696)

V3 新规则下：
  follow : n=1576  EV=+8.15%  WR=57.8%  median=+2.95%
  blind  : n=5696  EV=+7.33%  WR=55.4%  median=+1.84%
  skip   : n=976   EV=+4.73%  WR=52.3%

  follow edge: EV +0.82pp  WR +2.4pp       ← 真实正 edge（小但有）
  skip edge  : EV -2.60pp  WR -3.1pp       ← 负向筛选有效
```

**所以 V3 下实情是**：
- 真实 follow edge 约 **+0.82pp**（不是旧版宣称的 +3.67pp，也不是 -1.89pp）
- 真实 skip edge **-2.60pp**（负向筛选仍明显有效）
- 系统的"避坑"能力比"挑赢家"能力强很多

## 为什么 look-ahead 如此严重

看个具体例子：

- 2024 Q3 公告期（约 10 月下旬），同一机构一口气公告了 50 只股票的增持
- 旧逻辑左切 `notice_date < event.notice_date`，对这 50 个事件各自决策时，可以看到这组内其他 49 个事件的 60d 收益——**但那些 60d 收益要到 2025 年 1 月左右才确认**
- 也就是说，**决策时用了"未来 3 个月的信息"来判断"现在要不要跟"**

在一个牛市/均值上升的时期，这种 look-ahead 会让系统看起来效果很好（因为近期 well-performing 的样本不成比例地进入训练集）。

---

## 这意味着什么

1. **不能往 GitHub 上宣称"+3.57pp alpha"** —— 那是假的
2. **简单的"机构历史 EV KNN"本身不够** —— 需要更丰富的特征
3. **前进路径明确**：
   - **Step A（立即）**：Qlib 按 `follow_return_60d` 重训（用 Alpha158 + GPCW + 事件级特征），看能不能找回 alpha
   - **Step B**：加更多规则筛选条件（溢价 ≤ X、同期机构数、行业动量对齐等）
   - **Step C**：如果真的没 alpha，诚实告诉用户"系统目前只能做风险提示（Skip 档），不能给正向 follow 信号"

## 双口径 KNN 的意义

虽然 V2/V3 数字不好，但双口径本身的机制仍然有价值：
- **展示层**：UI 能同时看到短期和长期表现分歧
- **风险管控**：分歧时降档为 watch，避免高置信押注
- **信号丰富度**：用户能看到 "该机构近期表现" vs "历史基线"，有助于决策

当后续 Qlib / 特征工程加入后，双口径机制是保留的。

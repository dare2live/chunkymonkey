## 2. 产业链层设计 — A 股"分层→稀缺层"的数据化边界

### 2.1 核心翻译: Serenity 链谱三要素在 A 股的可得性

Serenity 的链谱 = 层级结构 × 稀缺判定 × 证据成色 (W1+B2+E1)。逐项判定哪些能数据化:

| Serenity 要素 (语料) | A 股数据近似 | 表/接口 (现实状态) | 判定 |
|---|---|---|---|
| **层级结构** (downstream→materials 八层, W1) | **没有现成数据**。概念板块 (dc/ths) 是平面标签 ("CPO 概念"), 不含上下游方向; 申万 L2/L3 是行业分类不是链位置; iFinD 产业链工作流 research-only (hologram #28: "无任何表") | — | **必须人工/LLM 补** → ①skill 产出 ②yaml |
| **成员归属** (谁在链上) | 概念成分 + 行业成分 | ths_member (全量带 in_date) / dc_member (2025+ 回填中, 探底 E8 进行中) / index_member_all 申万 L2 (真 PIT, 2003 起) | **可数据化**, 但只到"平面归属", 层级仍靠链谱 |
| **稀缺层判定: 供给侧坍缩到 1-2 家** (B2.1, 2025-10-28) | 链层内 A 股标的数 + 申万 L3 成分数 + 市占率 (年报, 人工) | 链谱 yaml 自带 (数节点); 市占率人工 | **半数据化**: 数公司数可自动, "全球就 2 家"的判断必须研究流 |
| **稀缺层判定: 毛利转化/提价权** (B2 核心: "Gross Margins > GW capacity", 2025-10-28; "必须变现为 operating income", 2026-03-13) | 毛利率环比/同比趋势 + 预收账款 + 存货周转 + 业绩预告超预期 | TuShare fina_indicator / forecast / express (171 接口可用, 未接) | **可数据化** (季频, 公告类双锚: ann_date ≤ t-1) |
| **售罄/排队信号** (B2.4: "sold out until 2027") | 业绩预告上修 + 调研纪要/互动易"满产满销"措辞 + 扩产公告 | forecast 可量化; 文本类研究流 | 混合 |
| **价格弹性/实物价格遥测** (W6: SMM 现货价当仪表盘) | 上游材料现货价 (光纤/磷化铟/稀土/碳酸锂等) | 无现成接口; SMM/百川盈孚类需另购 | **缺口** — 中期可选, 不进本期设计 |
| **板块资金流向** | 行业/概念资金流 | moneyflow_ind_dc (2024+, E8 探底中) / moneyflow 个股 (W1-2 回填中) / raw_fund_flow_daily (akshare 在库, 仅方向参考) | **可数据化**, 与三套组合共用同一回填, 零增量成本 |
| **链内传导/扩散** | 涨停传染 + 领涨-跟随 | limit_list_d (P0-b 回填中) + leader_follower 引擎 (已有) + 链谱 JOIN | **可数据化** — 但角色要澄清 (§2.3) |
| **融资结构毒性否决** (B6: "#1 thing is toxic financing structure", 2026-04-02) | **A 股版毒性**: 解禁洪峰 / 大股东高质押 / 减持计划进行中 / 定增破发倒挂 | TuShare share_float (解禁) / pledge_stat (质押) / holdertrade (增减持) — 均在 171 可用清单内, 未接 | **高度可数据化** — 这是全部移植项里数据最现成、与现有体系最正交的一件 (§3 ③) |
| **对手方信用加权** (E1 核心公式: 证据成色 = 数字 × 对手方信用, 2025-12-11) | 大客户结构 (前五大客户占比 + 客户是谁: 海外大厂链/国内大厂链/政府) | 年报附注, 无结构化接口 | **必须人工/LLM 补** → 链谱节点属性 (counterparty_tier), 研究流维护 |
| **证据成色三档** (W2: confirmed/likely/speculative, 2026-01-16) | — | 链谱 yaml 的 edge 属性 + 证据卡 | 设计直接照搬 (这是他方法里最工程化的部分) |
| **OSINT 信息发现** (W3 五件套) | A 股对应物: 互动易/e互动问答、问询函、环评公示、招股书供应商章节、海关数据、招聘 JD | 全部文本类 | **必须研究流补** → skill 的 A 股源路径节 |

**结论**: "分层"完全靠链谱维表 (人工/LLM 建, 数据无法替代); "稀缺层判定"六个子判据里 3 个可数据化 (毛利趋势/资金流/成员数)、2 个混合、1 个纯研究流; "证据成色"是纯设计移植零数据成本。**所以落地形态必然是混合: skill 养链谱, 引擎吃链谱。**

### 2.2 PIT 红线 — 链谱的后视污染 (本设计最重要的一条诚实声明)

今天人工构建的"AI 算力链谱"**不可避免含后视与幸存者偏差**: 我们知道 2024-2026 谁涨了, 链谱会无意识向 winner 倾斜 — 这与"概念成分用当前快照回测 = 教科书级 leakage" (hologram 盲点原文) 同构, 但更隐蔽, 因为污染发生在人脑里而不是 JOIN 里。硬规则:

1. **freeze-date forward-only**: 每条链谱节点/边带 `as_of_date` (= 我们写入的日期) + `evidence_ref`。回测里 t < as_of_date 的日期**不得使用该条目**。等价于 Serenity 自己的纪律 "most returns are made before official confirmation" (2026-05-26) 的反面镜像: 我们只能从写入日起向前赚, 不能假装早就知道。
2. 历史回测若要用链结构, 只能用**机械可复现的成员关系** (ths_member in_date / dc_member 快照 / 申万 L2 in_date-out_date) — 平面归属可 PIT 回放, 人工层级不行。
3. 链谱条目 append-only 版本化 (同纪律件 #9: 维表版本化, 禁止按事后表现挑选); 删除/降级节点保留 `removed_at` + 原因, 对齐 Serenity 自己的 SSYS 纠错协议 (2026-01-17: 区分哪句错/哪句仍成立, 公开留档)。
4. 链谱驱动的任何特征进 panel → 自动落入纪律件 #4 (相对提升 ≥+50% 触发 pit-audit) + #11 (短史 add-on only)。

### 2.3 涨停传染的角色澄清 (防止把"发现时刻"当"领先信号")

Serenity 的 alpha 定义在"市场发现之前" (B4: "before the market discovers them", 2026-03-19); 涨停传染恰恰是**发现时刻本身** — 它是套三题材扩散的工作域 (扩散中段跟随), 不是 Serenity 式早期信号。A 股语境下与他的"早期"真正同构的近似物, 按可得性排序:

| Serenity 早期信号 | A 股近似 | 状态 |
|---|---|---|
| 营运指标与股价脱节 (B4: "disconnect between stock prices and operational indicators", 2026-02-26) | **under_reaction 引擎** (已有, 7 引擎之一) × 链谱卡点层过滤 | 引擎已在, 缺链谱交集 |
| 美股链先涨 → 供应链下层后定价 (B1 漏斗) | **海外映射滞后**: 美股光模块/算力链异动 → A 股同链层标的的滞后响应窗口 | 需美股行情数据, 中期可选; 先用研究流人工盯 (skill 的 watchlist 节) |
| 时间线提前 = alpha (B11: CPO 量产 2027→H2 2026, 2026-05-11) | 扩产公告/招股书/环评里的量产时点变化 | 纯研究流 |
| 财报前置定价 (B5: 市场前瞻 8-18 个月) | 业绩预告 (forecast) 与一致预期差 | report_rc 族已在套二 P2-b 排期, 不重复 |

**因此链谱对涨停传染的增量主张只有一个、且可预注册检验**: 平面概念共现传染 vs **带方向的链内传染** (上游卡点涨 → 下游次日响应率, 对比无方向基线) 是否有差。这就是 ④引擎激活后的第一个判决实验 (§4.3), 阴性则链谱只保留研究流价值, 不进量化通道 — 阴性结果归档算合格产出 (D 蓝图纪律)。

## 4. 落地形态 — 混合: skill (即时) + 维表 (即时) + veto 探针 (W2-3) + 引擎 (条件)

### 4.1 形态判决

| 候选形态 | 判决 | 理由 |
|---|---|---|
| 纯 skill (研究工作流) | 不够 | 产出物若不落结构化维表, 每次调研一次性消耗, 无法被引擎/版面/回测消费 — 违反"真相源唯一" |
| 纯引擎 (每日跑批) | 当前不可行 | 分层判定无法自动化 (§2.1 第一行); 强行自动化 = 拿平面概念冒充链谱, 重蹈 theme 引擎拿 13 个 L1 行业冒充题材的现状 (hologram 已点名) |
| **混合: skill 养维表, 引擎吃维表, 版面读引擎** | **采纳** | 人做机器做不了的 (分层/证据/对手方), 机器做人做不动的 (每日全市场扫稀缺层温度) |

## 5. 市场感知版面 UI — "产业链" tab

三栏布局, 全部只读 (mart / yaml), 遵守数字出口纪律 (无 lineage 不显示):

### 5.1 左: 链图 (结构 + 温度)

- 纵向层列 = 链谱 layer 顺序 (上游材料 → 设备 → 器件 → 模块 → 系统/应用), 直接渲染 industry_chain.yaml — **看层先于看票** (skill 原则: "rank the layers before naming companies")
- 节点 = A 股标的 chip: 颜色 = 层温度 (④激活前用申万 L2 5 日资金流近似; 激活后用 mart 链层温度); 角标 = 角色 (controls/supplies/benefits/story 四类, story 类灰显)
- 边 = 供应关系, **线型 = 置信档**: 实线 confirmed / 虚线 likely / 点线 speculative (Serenity W2 三档的视觉化, 2026-01-16) — 用户一眼看出哪段链是证据哪段是推测
- 结构性 veto 命中节点打红色叹号 (解禁/质押/减持在期), hover 显示具体事项与日期

### 5.2 中: 卡点榜 (稀缺层排序)

- 按卡点分排序的层列表, 每层展开显示分量构成: 层内标的数 / 毛利趋势分位 / 资金流领先度 / 传染方向命中 — **每个分量可点开回溯到表行** (lineage 链, 反"各算各的")
- 月度链温度计: S→F 分档 (Serenity W10 tierlist 的移植, 2025-11-22), **每次档位变更必须留变更原因行** (append-only), 与 dc 题材生命周期引擎的 lifecycle_stage 并排对照
- 顶部常驻一行小字: "卡点分 = 结构温度, 不是买入信号; 量化消费须过 ablation gate" — 防版面数字旁路成交易依据

### 5.3 右: 证据链卡片 (E1 三档 + W11 对账闭环)

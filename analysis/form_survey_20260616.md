## 1. 四维 measured 发现

### D1 分布分层 (禁全历史平均)
- 基线: s1底部14.8% / **s1.5突破3.4%** / s2上升19.2% / s3顶部31.3% / s4下跌31.2%
- **突破态窄是结构性的**: s1.5 占比逐年锁死 2.79%-4.0% (极差 1.2pp), 与 2024 熊/2025 牛无关。市场态漂移全压在 s2↔s4 跷跷板 (2024 下跌49%/上升8% → 2025 下跌10%/上升36%)
- range_pos 耦合: s1底部 p50=0.27 / s2上升 p50=0.81 / s4下跌 p50=0.16 (强单调) — **但 s3"顶部" p50=0.52 (非高位)**
- MACD零轴强自洽: 底部88.6%在零下 / 突破·上升82%在零上 / 下跌主回零下; **s1.5 与 s2 零轴几乎同质 (都~82%)**

### D2 直觉映射 (用户形态库覆盖)
- 5 态只干净覆盖 2 角: **stage2=高位+上行 / stage4=低位+下行**; 其余直觉形态全 gap
- **GAP1 无横盘标签**: 无"无趋势"态, 横盘被塞进 s3/s1, 未被正向编码
- **GAP2 stage3 误标**: 最大态 (31.3%) 但位置弥散 (HHI 0.479, 仅 20.6% 真高位, 64% 中位) = "派发/滚落"非"顶部"
- **裁定: 位置 (range_pos) 必须独立成正交轴** — stage 与位置多对多, 单靠 stage 定位不了形态 (印证用户"高位/低位 × 上涨/下跌"两轴直觉)

### D4 转移序列 (惯性 vs 剧本)
- **惯性真**: 对角自留 0.55-0.93, 平均停留 4.7/2.2/13.8/8.5/14.0 天, MACD/range_pos 语义自洽 → 非识别器抖动噪声
- **形态学剧本假**: 规范周期前向边 (底1→突破1.5→上升2→顶3→下跌4) 只占切换的 **26.4%**, 74% 跳级/逆行
  - 突破(1.5) 离场 **68.9% 直跳顶部(3)**, 仅 12% 接上升(2) — 突破不导向上升腿
  - 底部(1) 离场 84% 直跳下跌/顶部, 跳过整个上升腿
- 根因: stage3 avg range_pos 0.53 < stage2 0.80 → "顶部"识别的是派发/回落非价格高点

## 2. F0 裁定

**现有 Weinstein 5-stage 作为单一有序标签, 不适合当 segment 地基 (measured 证明):**
1. 不分前瞻方向 (RankIC≈0, 下跌≥上升, 五态挤一团)
2. 轴混叠 (位置与趋势多对多, 单标签定位不了形态)
3. stage3 误标 (派发非高位)
4. 缺横盘标签
5. 序列非有序剧本 (74% 非规范转移)

**这不否定的 (失败先承认但不过度外推):**
- stage-conditional **框架本身**未被否 — 本次是截面 IC/分离度诊断, 不是含成本 backtest 也不是 episode 评估。IC真≠能赚钱 / IC低≠框架死 (§4.5)。主升浪猎手 = 突破事件检测器 → 候选内因子排名, 该路径未测
- building blocks 是有信息的: range_pos 对 底/上升/下跌 干净耦合; MACD零轴强自洽; dwell 有真惯性

## 3. F1 重设计方向 (data-backed, 待用户拍板)

不再拿 5-stage 单标签当 segment 原语, 改用 **正交轴** (F0 证明这些 building blocks 有效):
- **轴A 位置**: range_pos → 低/中/高 (= 用户"高位/低位", 干净耦合)
- **轴B 趋势动能**: MACD零轴 + MA斜率 → 上行/下行 (= 用户"上涨/下跌")
- **轴C 横盘 (新增)**: 显式无趋势判据 (ADX低 / 区间宽窄 / MA走平) — 现在缺
- **突破当 event-in-context** (前接底部盘整 + 位置突破 + 放量), 不是独立瞬态标签 — 因为裸突破不导向上升; 这正是主升浪猎手需要的
- "形态" = (位置 × 趋势 × 横盘flag) 的 cell; 主升浪/突破 = 叠在上面的上下文事件 — 比 Weinstein 5态更贴用户形态库 (高位/低位/横盘/底部盘整 × 上涨/下跌)

> 转正铁律: 任何 cell/事件最终须过 execution-aware 含成本 OOS backtest (C-R1/C-R2), 不凭 IC 选 cell (§4.5)。

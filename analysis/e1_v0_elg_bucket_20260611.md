## 判读

1. **二分法 no-go**: "特大单净流入 = 洗盘确认 = enhance" 的原设计方向性不成立 (inflow 不优于 outflow)。
2. **倒 U 型是更强的发现**: 两端极值都差 (极端流出 = 真出货; 极端流入 = 反抽诱多/拥挤),
   温和区间 (Q3/Q4) 最好 — Q4 vs Q1 win20 差 +10.9pp (deep) / +10.2pp (mild), avg20 差 ~+1.4pp。
   与 user_vision_hologram 的核心实证一致: 91% 真主升浪是温和模式, 极端主力痕迹是坏信号。
3. **L2 gate 设计修订建议** (B 蓝图 §2 待更新): mode 从 {流入 enhance / 流出 veto} 改为
   **{两端极值 veto / 温和区间 enhance}**, 分位边界进 Optuna search space (不拍死 20/80)。
4. 倒 U 在两个独立公式上同形复现 + 每桶 n>3,200 → 非单桶噪音; 但仍是单 regime 8 个月,
   **W3 判决实验 (TuShare moneyflow 2018+ 全期) 必须复验该形态**后才进生产 gate。

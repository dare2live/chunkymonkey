# 市场感知数据接入需求评估 — 2026-05-29

> 回答: "把市场感知做准确有效, 需要接入哪些数据(概念标签/产业链图谱/申万分类等)?"
> 方法: web 深度研究(A 股数据生态 6 维度) + 项目数据源盘点 + 实证验证
> 核心结论: **行业分类层面(TDX/申万/越细)板块轮动一律均值回归, 换分类体系救不了; 真正的 alpha 在概念主题层, 但所有概念/产业链数据 90% 是 current snapshot + 滞后维护, 直接回测必 leakage — "每日快照落库"是市场感知能否做准的工程命门**。

## 1. 核心结论(先行)

| 发现 | 含义 |
|---|---|
| **行业分类(申万/TDX/L1/L2)板块轮动一律均值回归** | 实测 IC -0.065~-0.070, 换分类体系无救 |
| **真正的轮动 alpha 在"概念主题层"** | 题材(猪周期/AI算力/机器人)才是轮动载体, 不是产业行业 |

| **项目很多数据 schema 已有但没积累** | 关注度 13 天/盈利预测 1 天/概念 current — 最便宜的改进是把已有 sync 加进 daily_update.sh |

## 3. 实证: 换更细行业分类救不了板块轮动

> 本 session 用 fact_sector_momentum_daily(TDX L1) + 自建 TDX L2 / 申万 L1/L2 完整回测, 819 天

| 分类 | 板块数 | ret_20d→fwd_20d IC | IR | 强弱价差(top-bottom) |
|---|---|---|---|---|
| TDX L1 | 13 | -0.017 | -0.04 | -0.06% |
| 申万 L1 | 30 | -0.070 | -0.23 | -0.91% |
| TDX L2 | 56 | -0.069 | -0.25 | -1.14% |
| **申万 L2** | 108 | -0.065 | -0.27 | -0.96% |

**结论**:
1. 所有行业分类层面 IC 都是**负的(均值回归)**, 越细越明显(弱板块 forward 反而强)
2. **换申万(更细更同质)没有救板块轮动** — 申万 L2 IC -0.065 跟 TDX L2 -0.069 几乎一样
3. 行业分类本质是"产业属性", 不是"题材属性" — 真正轮动在概念层
4. 月度轮动(动量/反转)都**跑不赢全板块等权 beta**(年化 +11.9%)

**这把"接入更细行业分类"从优先级里排除了** — 申万项目已有(L1/L2), 但对板块轮动无增量价值。申万真正的价值在**风格中性化 + 个股行业 beta 剥离**(给个股 ML 用), 不在板块择时。

## 7. PIT 快照落库 — 工程命门

**最重要的一条**: 概念/产业链/关注度/景气度数据 **90% 是 current snapshot + 滞后维护**, 直接用今天的成分回测历史 = leakage(违反项目宪法 §4.1/§4.2)。

| 解法 | 说明 |
|---|---|
| 方案 A(买) | tushare ths_member 有 PIT 历史(付费) |
| 方案 B(自建) | **从今天起每日落库快照**, 12-18 月后有干净 PIT 历史 |
| 必须避免 | 用 current 概念成分回测 2023-2025(前视偏差) |

**这跟之前 industry_history 只有 9 天是同一个问题** — 项目缺的不是"接入能力", 是"每日落库的纪律"。

## 9. 一句话总结

**把市场感知做准确有效, 最关键的不是"接入更多数据源", 而是: (1) 立刻开始每日快照落库已有的概念/行业/关注度/景气度数据(PIT 命门, 成本几乎为零), (2) 补同花顺/东财热门概念(真 alpha 在概念主题层, 不在行业分类层 — 已实证申万/TDX 换得再细板块轮动都是均值回归), (3) 补免费的融资融券, (4) 自建产业链图谱(关联动量溢出学术证实有效)**。项目已有申万 L1/L2 + LHB + 资金流 + 同业估值 + 持仓链, 缺的是概念历史 + 融资融券 + 真产业链 + 舆情 NLP, 而最大的工程命门是"没有每日落库纪律导致概念/景气度数据只有几天"。

# ChunkyMonkey可行性分析

日期：20260517  
对象：100万、5只、T+1  
目标：年化30%、回撤>-20%、月胜55%

## 0. 假设与口径

本文拆成两件事：Grinold-Kahn 下需要多高 IC 与宽度，以及公开市场中多少相近参与者做到过。基础口径：252日；20日持有；12.6次/年调仓；5只；组合波动28%-36%、基准32%；无风险2%；年化成本4%基准、2%-10%压力。成本依据为印花税、过户费、佣金与冲击成本[S13]。

5只股票不等于5个独立下注。若单期持仓数为 \(N\)，平均残差相关为 \(\rho\)，则：

\[
N_\text{eff}=\frac{N}{1+(N-1)\rho}, \quad
BR=N_\text{eff}\times \frac{252}{H}
\]

当 \(N=5,H=20,\rho=0.30\) 时，\(N_\text{eff}=2.27\)，\(BR=28.6\)。若5只股票高度同向，\(BR=12.6\)。本文用 \(BR=25\) 为基准，并报告12.6与50的敏感性。

## 1. 数学反推：30%目标需要什么 IC

Grinold-Kahn 基本式：

\[
IR=IC_\text{eff}\sqrt{BR}
\]

\[
R_\text{net}\approx r_f+IR\times \sigma_p-C
=r_f+IC_\text{eff}\sqrt{BR}\sigma_p-C
\]

因此目标收益 \(R^\*\) 对应的有效 RankIC 为：

\[
IC_\text{req}=\frac{R^\*-r_f+C}{\sigma_p\sqrt{BR}}
\]

注意：这里的 \(IC_\text{eff}\) 是已经考虑组合构建约束后的“有效 IC”。若原始 RankIC 到组合收益之间还有转移系数 \(TC\)，则：

\[
IC_\text{raw}=\frac{IC_\text{eff}}{TC}
\]

长-only、不能做空、5只集中持仓通常使 \(TC<1\)。若 \(TC=0.6-0.8\)，则原始 RankIC 要比下表高25%-67%。

### 1.1 30%年化的跨维度计算

以 \(R^\*=30\%, r_f=2\%, C=4\%\) 为基准，需解释的净超额为32个百分点：

| 年化波动 \(\sigma_p\) | \(BR=12.6\) | \(BR=25\) | \(BR=50\) |
|---:|---:|---:|---:|
| 28% | 0.322 | 0.229 | 0.162 |
| 32% | 0.282 | 0.200 | 0.141 |
| 36% | 0.250 | 0.178 | 0.126 |

Claude 的“30%需要 RankIC 0.195”在下列假设下基本成立：有效 \(BR\approx25\)、组合波动约32%、年成本约4%、无风险2%。直接代入：

\[
IC_\text{req}=\frac{0.30-0.02+0.04}{0.32\times5}=0.200
\]

若不计无风险与成本，\(0.30/(0.32\times5)=0.188\)。因此0.195合理但不保守：若 \(BR=12.6\)，需0.25-0.32；若 \(TC=0.6-0.8\)，原始 RankIC 约0.31-0.53。

### 1.2 当前 RankIC=0.025 能产生什么

按基准 \(BR=25,\sigma_p=32\%\)：

\[
R_\text{gross alpha}=0.025\times5\times0.32=4.0\%
\]

扣除4%成本、加2%无风险后，理论净收益约2%。若 \(BR=12.6\)，毛 alpha 约2.8%；若成本6%-10%，净收益为 -5.2% 到 -1.2%。所以 Claude 的“-1.6%/年”不能仅由 RankIC 0.025 推出，必须隐含约5%-6%成本或较低宽度；但与实测 -2.8% 到 -9% 同量级。

### 1.3 成本与换手约束

20日持有、每期全换仓，约12.6个完整换手周期。卖出印花税0.5‰，过户费买卖双向0.01‰，佣金按零售常见万1至万3计，未含冲击成本时一轮买卖约6-12bp；若叠加盘口冲击和成交延迟，零售小市值策略常见一轮成本可达20-80bp。年化成本：

\[
C_\text{annual}=12.6\times C_\text{roundtrip}
\]

若要把年成本压到4%，单轮全换仓成本上限约32bp。若单轮实际60bp，年成本就是7.6%，当前 IC 的全部毛 alpha 会被吃掉。

### 2.4 零售量化平台与回测-实盘缺口

聚宽、米筐、优矿、BigQuant等平台提供回测、模拟或策略展示，但未见可审计、剔除幸存者偏差的“全平台前0.1%策略实盘6个月后收益”统计。Ricequant 文档定位为回测与实时模拟工具[S15]；BigQuant 文章给出动量策略加入三类摩擦后年化从28%降至19%的示例[S14]。平台单个高收益案例不能作为30%目标的基准证据。

### 2.5 零售投资者实际收益

中证投服中心2024年度调查显示，受访者持仓10万以下占38.19%，10-50万占36.29%，50-300万占20.20%，300-1000万占3.67%，1000万以上仅1.64%[S16]。上海证券报调查显示：2022、2023年个人投资者全年盈利占比分别为37%、32%；2025年为57%，其中证券资产50万元以上投资者盈利占比64.77%，50万元以下为53.46%[S17]。100万元零售账户可投范围大于小户，但研究、交易与风控基础设施仍不能类比5亿以上机构产品。

## 3. 真实约束：5只长-only能否数学上达到30%

严格说，“数学上”可以：若有效 \(BR=25,\sigma=32\%,C=4\%,r_f=2\%\)，只要 \(IC_\text{eff}\approx0.20\) 即可达到30%。问题在于这个 IC 是当前0.025的8倍，且还是有效 IC；若长-only转移系数为0.6-0.8，原始 RankIC 需0.25-0.33。

| 情景 | 参数 | 推导净年化 |
|---|---|---:|
| 最优但苛刻 | \(IC=0.12,BR=50,\sigma=36\%,C=3\%\) | \(2%+0.12\sqrt{50}36%-3%=29.5%\) |
| 当前信号基准 | \(IC=0.025,BR=25,\sigma=32\%,C=4\%\) | \(2%+4%-4%=2%\) |
| 当前信号压力 | \(IC=0.025,BR=12.6,\sigma=30\%,C=8\%\) | \(2%+2.7%-8%=-3.3%\) |

30%还要同时满足最大回撤-20%。5只等权组合的波动下限可由：

\[
\sigma_p=\sigma_s\sqrt{\frac{1+(N-1)\rho}{N}}
\]

若单股波动45%、\(\rho=0.30\)，5只组合波动约29.8%；若 \(\rho=0.50\)，约34.8%。30%收益、-20%最大回撤对应 Calmar=1.5。对高波动5只组合，除非择时和止损极强，否则回撤约束比年化收益约束更难。

月度胜率55%不是最紧约束。若月收益近似正态，\(P(r_m>0)=\Phi(\mu_m/\sigma_m)\)。30%年化、32%波动对应月胜率约59.5%；真正难点仍是 IC、成本与回撤。

### 3.1 机构30%+依赖什么

公开数据中，2025年百亿量化私募平均37.61%[S11]，但对应的是强牛市、全市场覆盖、高分散持仓、低延迟执行、风控模型与机构费率。2024年市场中性私募平均只有3.86%[S8]，说明“对冲”本身不创造30%，它主要降低 beta 与回撤；30%+通常来自高宽度选股 alpha、beta暴露、风格顺风或杠杆/衍生品管理的组合。

### 3.2 宽度差异

| 组合 | 持仓 | 持有期 | 简单下注数 | 相关调整后年度BR示例 |
|---|---:|---:|---:|---:|
| 当前零售 | 5 | 20日 | \(5\times12.6=63\) | 12.6-35 |
| 100只机构组合 | 100 | 10日 | 2520 | 约200-300 |
| 1000只高宽度量化 | 1000 | 1-5日 | 5万-25万 | 约1000-5000+ |

即使相关性调整后，机构宽度仍常是当前约8-100倍。根据 \(IR=IC\sqrt{BR}\)，宽度提高16倍等价于 IC 提高4倍。

### 3.3 长-only alpha 损失

若一个截面因子的多空收益关于市场中性基准近似对称，top组合超额为 \(+a\)，bottom组合为 \(-a\)，多空 spread 为 \(2a\)。长-only只能拿到 \(a\)，理论上先损失约50%的截面 alpha；再加上行业、市值、涨跌停、不能做空高估股票等约束，经验上有效转移系数常落在0.5-0.8。也就是说，长-only不是不能赚钱，而是同样 RankIC 下 IR 显著低于多空或指数增强体系。

## 5. 与 Claude 数字逐条比较

1. “当前 RankIC 0.025、20日、5只、12.6周期，期望-1.6%/年”：部分验证。IC 0.025本身给出约2.8%-4.0%毛 alpha；变成-1.6%必须加入约5%-6%年化成本、较低有效宽度或负 beta。若实测为-2.8%到-9%，说明成本、滑点、风格暴露或信号衰减已经压过毛 alpha。

2. “达到30%需要 RankIC 0.195”：在 \(BR\approx25,\sigma\approx32\%,C\approx4\%,r_f\approx2\%\) 下验证，本文计算为0.200；若不计成本和无风险为0.188。分歧在于 Claude 没显式说明 \(BR\)、成本和转移系数。若采用保守 \(BR=12.6\)，需要0.25-0.32；若考虑长-only \(TC=0.6-0.8\)，原始 RankIC 需约0.25-0.53。

3. “30%零售长-only 5只数学上近乎不可能，P<5%”：本文接受这个结论，但表述为“可由公式构造，现实可达概率低于5%”。理由是所需有效 IC 为当前约8倍，且公开数据中只有强牛市、机构高宽度或赛道集中产品才大量出现30%+。

4. “现实可达15%-25%”：需要限定条件。若保持当前5只、20日、RankIC 0.025，15%-25%不可达。若重构为更高宽度、更低成本、风险中性化、持仓20-80只，且有效 RankIC 提升到0.08-0.14，15%-20%可作为中期目标，20%-25%是强约束下的进阶目标。

## 6. 建议：目标与框架级重构

结论很直接：在“100万、5只、T+1、长-only、当前RankIC=0.025”的组合下，30%年化不是工程调参问题，而是数学输入不足。当前优先目标应从“追30%”改为“证明稳定正 alpha”：净年化5%-10%、最大回撤低于-20%、相对沪深300为正。完成后再把生产目标提高到15%-20%；20%-25%只能作为重构成功后的拉伸目标。

若仍要求30%，最低可行路径是整体重做：

| 模块 | 最低要求 |
|---|---|
| 信号 | 有效 RankIC ≥0.10 且 \(BR≥100\)，或在当前BR下有效 RankIC ≥0.20 |
| 持仓 | 从5只提高到20-80只；若仍5只，回撤目标与30%收益目标冲突严重 |
| 期限 | 5-10日可增加宽度，但必须证明成本后收益；20日下需极高IC |
| 成本 | 单轮全换仓成本控制在30bp以内，年化成本≤4%-5% |
| 风控 | 行业、市值、波动率、流动性、涨跌停、ST显式约束 |
| 组合 | 从排序买前5改为优化器：预期收益、风险、成本联合求解 |
| 验证 | walk-forward、留出年份、模拟实盘、成交回放 |
| 若允许改变约束 | 加入指数期货/ETF对冲或市场中性框架；否则接受长-only alpha 折损 |

最终判断：Claude 的数量级基本正确，但0.195是偏乐观的有效IC口径。对当前形态，30%年化/回撤-20%/月胜率55%同时成立的现实概率按1%-5%处理；更可辩护的目标是先把有效 RankIC 从0.025提升到0.06-0.10，同时把宽度从约25提升到80以上。没有这两个数量级变化，15%-25%也不是稳定可达目标。

## 冻结定义 (判断法典, 人话+机器话)

| 条款 | 人话 | 机器话 |
|---|---|---|
| 龙头 | 概念内当日涨停的股 (单一口径, 量比/新高臂留 V1) | `leader := limit_list_d[trade_date=t, limit='U'].ts_code ∩ dc_member[t].con_code` |
| 概念归属 | 事件日成分快照, as-of t (不许用未来成分) | `dc_member WHERE trade_date = t` (reconstructed 面板, G2-G4 验收后) |
| follower | 同概念非龙头、当日未涨停、t+1 open 可成交 | `con_code ∈ concept[t] − leaders[t]`, `t+1 open < stk_limit.up_limit` (盲点6 过滤) |
| 事件 | 概念当日新增龙头数 >= 2 且该概念 5 日内首次触发 (去连发) | `count(leader)>=2 AND no event in [t-4, t-1]` |
| forward 收益 | t+1 open 买入, t+6 open 卖出, qfq 口径, 双边成本 27.282bps | `fwd5 = qfq_open[t+6]/qfq_open[t+1] - 1 - 0.0027282` # from yaml: paper_sim cost round_trip |
| 对照组 | 同日、日涨幅带 ±1pp 匹配、非该概念成员的股票, 同口径 fwd5 | 涨幅带按 daily.pct_chg 匹配, 每 follower 抽 3 个对照 |
| 极端热日 | e1 倒U 警示: 全市场涨停数最高 10% 分位的日子单独分桶 | `hot_day := limit_count[t] >= quantile(0.9)` 分桶报告, 不并桶判决 |

## 1. 持仓成本估算 (三方案并行实现, 敏感性对照)

**建仓窗口** = (上一披露期, 本披露期]:
- 固定季报: 上季末→本季末 (~63 交易日); 临时公告: 上次披露→本次 (可短至数日)。
- 增持=增量部分用窗口价, 存量沿用旧成本 → **加权平均成本法**: `新成本 = (旧股数×旧成本 + Δ股数×窗口价) / 新股数` (hold_change_num 给 Δ)。

| 方案 | 算法 | 定位 |
|---|---|---|
| **C1 窗口 VWAP (主推)** | `Σ(qfq_close×volume)/Σ(volume)` over 窗口 | 用户"成交量最大的几个时间点"直觉的连续严格化 — 全窗口按量加权, 比取 top-N 点稳健无挑点自由度 |
| C2 期末价 (对照) | 报告期末 qfq 收盘价 | 最保守锚, 敏感性下界 |
| C3 龙虎榜增强 | 窗口内该股 top_inst 机构席位上榜日的按额加权价; 无上榜回退 C1 | 上榜日≈真实建仓日, 有 19万行支持; 仅作增强不作主方案 (覆盖不全) |

**复权口径红线** (本项目血泪): 成本与卖价必须同一 qfq 口径。禁用 raw amount/volume 直算 VWAP 再与 qfq 价比 (单位/复权错配 = paper_sim NAV 暴跌反例)。统一用 `v_price_kline_qfq` 的 close×volume 加权。

**裁决纪律**: 三方案并行出数, 结论必须对成本方案**稳健** (方向一致) 才可信; 只在 C1 下成立 = 不采信 (mio: 不挑好看的)。

## 2. 机构收益测算 (episode 模型)

**episode** = 同一机构(holder_name_norm)×同一股票: 建仓(新进, 可多次增持)→ 部分了结(减持)→ 清仓(退出) 或 持有中。

| 环节 | 算法 |
|---|---|
| 卖出价 (退出) | 退出窗口 VWAP (与建仓镜像: 机构在 (上期,退出期] 内卖出) + 期末价对照 |
| 部分了结 (减持) | 减持量×减持窗口 VWAP = 已实现部分; 剩余持仓成本不变 |
| 持有中 | 最新期 qfq 价算浮盈, **标 unrealized 不与已实现混排** |
| 收益 | (卖出价-加权成本)/加权成本; qfq 口径自动含分红总收益 |

## 3. 机构画像 (擅长领域/收益/胜率)

- **维度**: holder_type 12类 / 申万行业 (v_sw_industry_pit, **入场时点的 PIT 行业**非当前) / 东财概念 (dc_member) / 市值段 / 年份分层。
- **指标**: episode 数 / 胜率 (已实现收益>0) / 中位+平均收益 / 平均持有期 / 年化。
- **样本量护栏**: episode < 10 的机构×维度格子标 `low_sample` 不进排名 (样本不足不冒充结论)。
- **分布 vs 趋势**: 按年份分层报告, 禁全历史平均冒充当前能力 (2019 的牛散 2026 未必灵)。

## 4. 跟随策略模拟 (R2 execution-aware)

| 规则 | 实现 |
|---|---|
| 信号日 | notice_date (page_update 保守锚) |
| 入场 | 信号日**次交易日 open** (qfq); **一字涨停不可成交** (stk_limit: open==up_limit 且 low==high) → 顺延至首个可成交日, 超 max_chase_days (参数, 默认3) 放弃该信号 |
| 出场 | 该机构退出事件信号日次交易日 open; 一字跌停顺延同理; 兜底 max_hold_days 参数 |
| 成本 | 佣金万2.5双边 + 印花税千1卖方 + 滑点参数 (默认 10bp) |
| **跟随对象 PIT 评级红线** | t 日选"值得跟的机构"只准用 **≤t 的 episode 战绩** (expanding window); 用全期战绩选=selection leakage (§4.5 stage_opt 反例直接变体, 死亡条款级) |
| 输出 | 含成本收益/胜率/max_dd vs HS300; 分机构类型/行业/信号类型 (临时 vs 季报) 分层 |

**先验诚实**: 季报信号滞后 31 天中位, 跟随的是"机构一个月前的动作"——alpha 可能已衰减; 临时公告 5 天锚是本策略真正的时效卖点。分层报告两类信号, 不合并平均。

## 7. 前端配套原则 (用户 2026-07-02 定调, edge 全界面适用)

- **页面布局/展示/可视化与后端匹配**: 每个前端卡片 ↔ 一个 SERVE entity/API, 展示什么后端就供什么, 不在前端拼装多源。
- **前端数据获取/加工/计算 = 独立小功能**: 每 widget 独立取数/独立渲染/独立失败 (坏一卡不坏整页), **禁长链条 init** (旧 app.js 657行链式加载 = 反例)。
- **简洁清晰 + 巧妙可视化大量数据**: 机构档案界面参考形态 — 机构画像热力图 (行业×胜率)、episode 时间线 (建仓→退出叠加股价)、跟随收益 vs HS300 曲线、分层小倍数图 (small multiples)。

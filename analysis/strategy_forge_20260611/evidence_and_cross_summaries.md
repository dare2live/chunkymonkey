## 2. 被忽略的实证结论 (两条是实锤矛盾)

1. **B 的 L3 建在 C 实测过的垃圾字段上**。B §2-S4/§4.1 直接消费 `moneyflow_ind_dc.rank` "现成 rank 字段", 而 C 的 M1 实测它是分页伪 rank (每 50 行循环, 与自算 rank spearman=0.07)。我本会话复测确认: 最新交易日 1021 行, 每个 rank 值出现 21 次, **max=50** — B 的 search space `sector_rank_max ∈ int(10,200)` 里 51-200 是物理死区。B 照蓝图实现 = L3 整层失效 + Optuna 在死区里白搜。
2. **B 的 L2 核心假设与 D 的前哨实测先验冲突, 无对账**。D 用同一份 moneyflow 样本实测: 5 日大单净流占比 vs forward 5d RankIC = -0.0121 (20 日窗, [初步]); B 把同一特征 (`elg_net_5d`) 当 L2 入场确认主轴。不是说 L2 已死 (D 自己声明 20 天不能定方向), 但两家同数据反先验、各写各的, cross 步骤缺失的直接证据。
3. **全项目期望值最高单项无人认领**。全息图把"CYQ 出货预警/退出端 (+10pp mean, 0 新数据)"列为最高杠杆、路线 1 排第一 — 三份蓝图全是入场/排序蓝图, 退出端只是各家附属参数 (B 两个 exit 参数、C 时间止损、D 一个 wr gate)。更糟: D §8 自评时**假设"C=退出引擎/组合层 owner"**, 而真实 C 是题材扩散 — 组合 NAV/总 max_dd 的 owner 真空被三个并行 agent 互相想象成"别人在做"。
4. theme/LF backfill (+5-10pp, 全项目唯一明确剩余 lift, 2-3 天工期) 只出现在 C 的**降级预案**里, 不是任何人的主交付。

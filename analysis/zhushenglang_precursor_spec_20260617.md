## 0. 用户纠偏要点 (本方案必须落实)
1. **结果倒推非信号正推**: 从已知赢家(fact_rally_ground_truth)学前兆, 不造前向信号回测。
2. **异常做成模型**: 换手率/成交量"放大"= 相对自身分布(VRN=换手率/MA20), 不是 ad-hoc 一窗比一窗。
3. **明×暗×筹码×价格 交互因子族**(§2): 不是单个 stealth 因子, 是整族状态。
4. **窗口要 deliberate**: 主力资金/放量/换手看几天? 多 horizon(当天/前3/5/10/20日)写清, 不顺手定。
5. **板块概念热度+资金轮动+龙虎榜**(§3): 现因子全个股层零板块维度 = 最可能藏答案处。
6. **鱼头/鱼尾签名**(§4): 研究起涨段(YGYQ)与顶部(FLZZ高位)特征 → 框定鱼身。
7. **组合搜索 ≠ 全塞一个模型**: 搜多种组合找增益最大, 但必带 overfit 闸(否则=+95.9% peek 同款选择偏差)。
8. **学 SOTA**: 微软 Qlib + 聚宽 + 同花顺暗盘 + 最新防过拟合/meta-labeling(研究 wf 进行中)。

## 1. 标的与样本 (D1 已有)
- 正样本: fact_rally_ground_truth is_true_rally=1 (4345, 突破后60-180天≥50%涨幅 AND max_dd>-20%)。
- 负样本: is_true_rally=0 (38857, 突破了但没成主升浪)。监督对比 = 在 event_date(起涨点)区分正负。

## 2. 明盘 × 暗盘 × 筹码 × 价格 交互因子族 (用户核心设计)
**原料**:
- 明盘 M = tushare moneyflow 主力净额比 = (buy_lg+buy_elg−sell_lg−sell_elg)/总额。
- 暗盘 D = 同花顺暗盘近似 = OHLC路径权重 X_8 × (sm+md 分单级额), signed(用户公式X_25适配日线; 注: 非真L2, 是日度近似, 须验有效性)。
- 筹码: winner_rate(获利盘%) + 其20日变化; 集中度=(cost_95−cost_5)/cost_50 + 其变化; 股价相对 cost_50(套牢/获利位)。
- 价格: 缩量回踩(SLHC)/放量滞涨(FLZZ)/60日区间位置(GWBZ高/DWBZ低)/20日趋势。

**交互状态 (M符号 × D符号 × 量级 × 筹码 × 价格)**:
| M | D | 量级 | 配 | 语义 | 对赢家预期 |
|---|---|---|---|---|---|
| − | + | \|D\|>\|M\| | winner低+价稳缩量 | 明打压暗吸筹(低吸) | 利好(鱼头候选) |
| + | + | 同向入 | 集中度↑+突破 | 共识看多/启动确认 | 利好 |
| + | − | \|M\|>\|D\| | 价突破 | 主力强势 | 利好 |
| + | − | \|D\|>\|M\| | 高位+FLZZ | 拉高出货 | 利空(鱼尾) |
| − | − | 同向出 | winner高位↓ | 一致出逃 | 利空 |
| − | + | \|M\|>\|D\| | — | 诱多/做T | 中性偏弱 |

**工程化**: (a) 离散态(6-8类 one-hot/类别特征喂GBDT) + (b) 连续交互项(M·D 符号积、M/D 比、|M|−|D|、M×winner_rate_chg、D×SLHC 等) + (c) 多窗聚合(下§5)。让模型/标签学哪些态预测赢家(以及哪些态预测鱼尾出场)。

## 3. 板块/概念维度 (漏的横截面信号; **实测板块基础率15.6pp跨度=最强单维**)
**实测裁定 (experiment_rally_precursor_stratified, f9f0d2ed)**: 申万**二级**板块基础率跨度 **15.6pp** (广告营销17.1%/煤炭16.4%→城商行1.5%, 11x) >> 市值×位置仅1.0pp。混池(旧错)把它冲销成AUC0.52。
**口径铁律 (用户3遍强调+项目06-11 ANOVA)**: 用**申万二级(131桶)非一级(31桶太粗)**; 行业聚合按 dim_index_member_history.as_of_date PIT成分 + 打 taxonomy_version 戳(申万切换坑§4.5)。
**caveat**: 静态板块membership基础率含**题材幸存**(煤炭2021/广告AI2023-25), **可交易信号是事件当时的板块同期热度/轮动**非静态标签。
因子(条件层非主信号, 研究定位"行业轮动模型多但OOS有效少"):
- (1) 申万L2 60/120日**残差动量**(剥市场beta, A股裸价格动量负IC); (2) 行业资金净流入占比=Σ成员主力净额/行业总成交额, [3,7,21]日多窗;
- (3) 行业拥挤度=估值分位×换手率环比二维分桶(低拥挤+高景气=加分, 高拥挤=反向风控闸); (4) 个股在L2行业内主力净额分位(龙头效应)。
- 龙虎榜(top_inst, 数据待注册): 机构净买强度(机构买-卖)/总成交额(阈值>15%靠谱/<5%弃)+量比≥3闸; V型非线性分桶(物极必反); 只做T+1~T+5短波段(20日衰减0); 含成本回测(5日+2.3%毛扣成本所剩无几§4.5)。

## 4. 鱼头/鱼尾签名 (框定鱼身)
- 鱼头(起涨段进场签名): YGYQ二次启动(SLHC缩量回踩×2 + 阳线 + 破前高 + VRN升) + 明暗共识入(M+D+) + winner_rate低位。
- 鱼尾(顶部出场签名): FLZZ放量滞涨高位(GWZZ) + 明买暗卖(M+D−|D|>|M|) + winner_rate高位 + 上影放大。
- 用法: 鱼头=入场触发, 鱼尾=出场触发; 鱼身=两者之间持有(顺势)。

## 5. 窗口设计 (deliberate, 不顺手定; 借鉴 Qlib 滚动范式 — 待研究回填)
- 每个原料因子取多 horizon: t当天 / 前3日 / 前5日 / 前10日 / 前20日 的 {均值, 和, 最大, 斜率/变化}。
- 资金类(M/D)用累计净流入(3/5/10/20日sum); 异常类(VRN/量比)用 当天值 + 5日均 + 10日max; 筹码用 t值 + 20日变化。
- 具体窗口集 + 因子全集 → 待 Qlib 研究综合后定稿(§6)。

## 6. 模型 / 验证 / 组合搜索层 (SOTA 研究 wf_721262ed 已回填: Qlib/暗盘/聚宽/防过拟合)
**模型裁决: 转 meta-labeling (López de Prado), 停止让 ML 预测方向** — 这正是 AUC0.52(方向无判别)的解, 且鱼身框架结构上本就是 meta-labeling:
- **PRIMARY(规则)** = 确认主升方向: 周线多头 + 二次突破入场(已验+2.81%/笔 p=1.0=primary已有edge, 这是上meta前提) + 量能确认。粗突破+0.12%无alpha=剔除出primary。
- **SECONDARY(ML)** = 只判 true/false breakout(该不该下注), 特征=§2交互族+§3板块L2 context, **不预测方向**。
- 指标从 AUC 换 **precision/F1 + 含成本Sharpe + max_dd降幅**(meta真增益是滤假阳/控回撤非提胜率; 用AUC评meta会误判无效)。
- secondary概率先 calibrate(isotonic/Platt)再映射仓位(sigmoid sizing/固定档), 不让模型自学仓位函数。

**标签层 (替固定horizon)**: trend-scanning — 每个候选入场点 forward span[5,60交易日]做OLS t-stat扫描, label=sign(t-value)取|t|最大horizon, **样本权重=|t-value|**(自适应主升浪长度不固定; 弱趋势自动降权)。落 task#40/#41。
**样本权重铁律**: average-uniqueness(1/并发生命期均值)+ sequential bootstrap — episode标签时间重叠违i.i.d.→in-sample虚高。**严禁用收益当权重**(研究实测F1坍塌0)。

**因子卫生 (Qlib借鉴)**: (a)补Qlib 26算子缺失族(CORR量价配合/RSV随机位置/IMAX-IMXD突破点相对位置=鱼头鱼尾签名/RSQR-BETA-RESI趋势质量/SUMP动能), 全用close/volume归一化保横截面可比, 窗口[5,10,20,30,60]; (b)资金/换手类全做**CNIR截面残差化**(逐signal_date对当期收益+动量截面回归取残差, 剥反身性/反转伪alpha, 系数只用<=t); (c)**暗盘必须项目自有逐笔/L2重算可审计版**(禁同花顺黑盒"暗盘资金"=二手派生不可PIT复算违真相源; 现OHLC路径近似仅探路标approximation); (d)横截面标准化(CSZScoreNorm)转排序学习。
**因子治理 (RD-Agent借鉴)**: 去重门(新因子与现集跨截面max相关≥0.9剔除); "新因子必须OOS超当前最优组合才采纳"(治单分数improve); 多种子≥10复跑报mean±std。

**验证层 (现有→加)**: shuffle-null(有,第一道筛) + purge+embargo≥250日(有) + **CPCV(新, N=6/k=2→15splits拼5条纯OOS路径)** + **PBO(新)** + DSR(有)。裁决= DSR p>0.95 AND PBO<0.5 AND **含成本年化分布下界>0**。组合搜索必带 **nested-CV**(外层CPCV选因子, 内层调超参, 防+95.9%peek)。CPCV算量爆炸→走 parallel-grid-runner 并发(read_only) + Modal。
**IC现实锚 (Qlib)**: 干净OOS RankIC 0.02-0.06=正常alpha, >0.1立即查leakage(比0.3红线更早), <0.01=无判别(当前买点状态)。
**walk-forward升级 (DDG-DA)**: 月度(20日)重训 + 可选regime相似度加权resample(主升浪是牛市regime产物); 先朴素baseline再上加权版对比。

## 7. 诚实前提 (研究三方独立印证, 已收敛)
**买点预测"哪个突破成主升浪"在个股单点二分类下=接近信噪比结构上限, 不是模型烂**: (1)项目三次实证0.528/0.51/0.52(purged-CV+shuffle-null=null); (2)Qlib干净PIT日频CSI300 IC仅0.03-0.05; (3)Avramov: ML截面alpha经成本+发表衰减+高流动性三杀-57%, 真实OOS Sharpe~0.30; (4)A股反转市非动量市, "龙头是市场选出来的不是预判的"。**别再在抓鱼头上耗主力资源**。
**仍可能突破0.5的窄缝(改问题设定非换模型)**: (a)难套利股(小盘/低流动/高波)+短命信号+另类数据; (b)日内/分钟微观结构(日频OFI IC≈0但分钟15.7%, 日频聚合抹平); (c)episode/排序设定替单点二分类。期望校准: 加完更可能把edge从0推到弱正(RankIC 0.02-0.04)非银弹。
**资源重心(研究+项目收敛, 真金白银tractable edge在此)**: (1)**鱼身延续**(二次突破+2.81%已验=tractable, 确认后顺势跟随); (2)**出场择时**(死叉=最差-2.25%, CYQ出货预警=最高价值单项却0代码=优先建); (3)**仓位管理**(把{edge,胜率,盈亏分布}转{收益,回撤}传递函数); (4)**板块L2热度条件层**(基础率15.6pp跨度=选对池)。+ meta-labeling控质量。
若 §2交互族+§3板块L2热度 全做完仍无 secondary edge → 买点接近随机的最终强证据, 方向题交用户裁。
